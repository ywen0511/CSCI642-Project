# Data availability

| input | origin | redistributed here? | how to obtain |
|---|---|---|---|
| ErrP-HRI raw EEG (EEGLAB .set/.fdt, documentation PDF) | github.com/stefan-ehrlich/dataset-ErrP-HRI, commit `4bc3e52469934aa0551a2261a6e4e899d156c28f` | **No.** The repository declares no license (GitHub API `license: null`); public availability does not establish permission to rehost. | `python scripts/decoder_improvement/acquire_inputs.py --out <DIR>` downloads the pinned commit archive and checks all 49 files (sizes, SHA-256) against `configs/decoder_improvement/external_inputs.json` |
| Prepared epochs (all bands) | derived from the raw EEG | **No** (raw-signal-bearing derived arrays) | `python scripts/prepare_data.py --raw-root <DIR>/data/raw/dataset-ErrP-HRI --config configs/decoder_improvement/preprocessing_<band>.yaml --out-dir <DIR>/derived/<band>`; deterministic: a fresh acquisition reproduced the study's 1-20 Hz arrays byte for byte (`acquisition_test_report.json`, `preflight.md`); expected hashes are in every fit's `provenance.input_hashes` |
| CBraMod pretrained weights | huggingface.co/weighting666/CBraMod revision `500543c7e30bda1b22bfd51a49301b238dee21fd`, `pretrained_weights.pth` | **No** (obtained from the official source) | same acquisition command (size 19,775,842, SHA-256 `0792cb80...8157178`); set `ERRP_WEIGHTS_DIR=<DIR>/weights` |
| Everything generated by this project (checkpoints with full training state, logs, CV and final predictions, calibration, configs, plans, decisions, reports, figures and their source data) | this study | **Yes**, GitHub Releases listed in `artifact_index.md` | `python scripts/decoder_improvement/release_tools.py fetch --tag <tag> --out <new dir>` |

Prediction tables contain trial IDs, labels and model outputs (no EEG samples), as in the original project Release.
Checkpoint archives contain model weights and optimizer state only, no EEG signals; fixed inference probes are stored
as trial IDs plus the SHA-256 of the scaled input and the model outputs, so they are reproduced from the regenerated
inputs. The acquisition command exits 2 (blocked) if the network or an upstream file is unavailable and 1 on any
checksum mismatch. The bundle is therefore **not** fully self-contained offline: the raw EEG and the pretrained
weights are external inputs.
