# 给 GPU agent 的启动提示词

将以下内容交给具有 GPU 和本项目文件访问权限的 agent。远端运行时，把工作目录改为实际 checkout 路径，并提供需要的只读文献或使用 README 中的公开来源。

---

请完成本项目的 EEG 阶段。先阅读 `README.md` 和 `docs/eeg_stage.md`，然后按照其中的范围、数据协议、交付接口和验收标准执行。

目标是在 ErrP-HRI robot 条件上训练 EEGNet，并微调预训练 CBraMod，公平评估两者的错误解码能力，交付两个固定解码器及供后续 RL 使用的逐 trial 错误概率。现在不要开展 SAC 或机器人环境工作。

请先检查已有实现，不要覆盖用户已有工作。已有 PDF、proposal 源文件及原始数据只读。你可以新增和修改 EEG 阶段的实现、配置、脚本、报告及派生产物。

执行要求：

1. 先做数据与事件审计，再冻结参与者划分和预处理协议。不要根据测试表现改变划分。
2. 原文缺失的设置需要查证或明确记录为项目选择，不得伪称为 Kim 的原始参数。
3. 两模型使用相同有效 trials、参与者划分和物理时间窗；模型必要的输入适配单独记录。
4. 先短测确认数据、训练和 checkpoint 正常，再使用 GPU 完成正式运行。记录 GPU 型号、显存、版本和实测耗时。
5. 模型选择和概率校准仅使用训练/验证参与者；最终测试参与者不参与拟合或调参。
6. 输出 `P(error)`，保留稳定的 subject/trial IDs 和真实标签，不在本阶段转换为 RL 奖励。
7. 交付可复现代码、完整运行命令、固定配置、权重及校准参数、评估报告、概率表和 artifact manifest。将代码与报告推送到本项目仓库，将 checkpoints 等训练产物上传到该仓库的 GitHub Release。
8. 不要将论文、原始 EEG、大权重、访问令牌或缓存提交到普通 Git。外部 artifact 记录位置和校验值。
9. 持续完成所有可推进的工作；若事件语义、必要数据或 GPU 权限等条件实际阻塞，说明证据及受影响步骤，并完成不依赖该条件的工作。不要编造结果。
10. 严格执行任务说明第 11 节：保留每个正式 run 的完整 `best.ckpt` 和可恢复的 `last.ckpt`（包括优化器等训练状态），上传 Release assets，并重新下载核验 SHA-256、推理和恢复能力。禁止只上传代码、只存分类头或只给 GPU 机器上的临时路径。权限不足时不得声称上传完成。

最终说明：完成了什么；两个模型的逐参与者指标；实际耗时；所有可运行命令与产物位置；代码 commit 和 GitHub Release 链接；checkpoint 下载校验结果；是否已满足 `docs/eeg_stage.md` 的验收清单；哪些协议与 Kim 文献不同。

---

这份提示词授权的是 EEG 阶段实现和实验，不代表已经运行或验证任何模型。
